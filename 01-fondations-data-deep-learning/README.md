# Phase 1 — Fondations Data & Deep Learning (Mois 1-2)

**Objectif :** maîtriser le pipeline complet de machine learning et deep learning en Python.

## Contenu
- Mathématiques appliquées (vectorisation, calcul matriciel, métriques : F1-score, WER, BLEU)
- Machine Learning classique (`pandas`, `numpy`, `scikit-learn`)
- Deep Learning avec PyTorch (MLP, CNN, intro Transformers)

## Sous-dossiers
- `notebooks/` — exploration, expérimentation
- `projets/` — projet étape versionné
- `ressources/` — cours, articles, cheatsheets

## Projet étape
Classifieur de données tabulaires ou d'images, avec évaluation des biais par sous-groupe.

## Critères de réussite
- Bat une baseline naïve
- Matrice de confusion analysée par sous-groupe
- Code versionné et documenté
