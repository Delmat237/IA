# Phase 4 — UX Inclusif, Multimodalité & Déploiement (Mois 7+)

**Objectif :** transformer les modèles en un produit utilisable par n'importe quel public.

## Sous-dossiers
- `ux-ui/` — normes WCAG, interfaces vocales/visuelles, cross-platform (Flutter, Next.js/PWA)
- `ethique-audit/` — robustesse face à la diversité des utilisateurs, model cards
- `projet-final/` — application complète de bout en bout (ex: assistant vocal hors-ligne santé/agriculture/services publics)

## Critères de réussite
- Test utilisateur réel avec le public cible
- Audit WCAG passé
- Model card publiée
